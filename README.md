# CSCI 3212 Algorithms Labs

Student-facing lab materials for the George Washington University CSCI 3212 Algorithms course, Fall 2026. The site uses Jekyll and the [Just the Docs](https://just-the-docs.github.io/just-the-docs/) theme.

## Contents

- [`index.md`](index.md): minimal site landing page and lab directory
- [`lab0/index.md`](lab0/index.md): Lab 0 setup, practice, and recursion material
- [`lab0/examples/`](lab0/examples/): complete runnable Python programs
- [`lab0/practice/`](lab0/practice/): starter programs for students

## Preview locally

Install a current Ruby 3 release and Bundler, then run:

```bash
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000/algorithms-labs-gw26/`. GitHub Pages can also build the site directly from the repository root.

## Attribution

Lab 0 follows Professor Rahul Simha's [Module 4: Recursion, Part I](https://www2.seas.gwu.edu/~simhaweb/cs1112/modules/module4/module4.html). Its lesson order and examples are retained, with Java programs adapted to Python and a short Python development setup section added for this course.
